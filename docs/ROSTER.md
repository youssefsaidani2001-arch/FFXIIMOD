# Ring of Pacts roster (51 summons)

Source: *Esper (Revenant Wings)* on finalfantasy.fandom.com (read through search
snippets, the wiki is blocked from the build session). Water beats Fire, Fire
beats Earth, Earth beats Thunder, Thunder beats Water; Holy and Non-elemental
sit outside the cycle. Rank III summons are one-at-a-time.

| Element | Melee I / II / III | Ranged I / II / III | Flying I / II / III |
|---|---|---|---|
| Non-elemental | Alraune, Chocobo / Tonberry / Odin, Gilgamesh | Sylph / — / Zalera, Zodiark | Garchimacera / Diabolos / Bahamut |
| Fire | Djinn / Balasa / Ifrit | Salamander / Lamia / Belias | Bomb / Wyvern / Chaos |
| Water | Sahagin / Cúchulainn / Leviathan | Shivan / Shivar / Shiva, Famfrit | Aquarius / Siren / Mateus |
| Thunder | Remora / Ixion / Shemhazai | Quetzalcoatl / Sagittarius / Tiamat | Ramih / Raiden / Ramuh |
| Earth | Goblin / Golem / Titan | Cactoid / Cu Sith / Hashmal | Gnoam / Atomos / Exodus |
| Holy | — | White Hare / Carbuncle / Ultima | — |

Boss-gated pacts (must be defeated first): Odin, Gilgamesh, Zalera, Zodiark,
Bahamut, Belias, Chaos, Cúchulainn, Famfrit, Mateus, Shemhazai, Hashmal,
Exodus, Ultima. Change the `boss` flag in `data.lua` to taste.

Black Chocobo appears in the wiki as a Rank I ranged Yarhi but is enemy-only
in Revenant Wings, so it is not in the ring.
